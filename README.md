# Screenshoti 📸✨

Нативное приложение для macOS для быстрого захвата, аннотирования и эстетичного оформления скриншотов (аналог Screenshot X / Xnapper с расширенными Pro-функциями).

Разработано на **Swift** и **SwiftUI** с использованием `ScreenCaptureKit`, `Vision` и `CoreImage`.

## ✨ Основные возможности
- **Модуль захвата (`ScreenCaptureKit` & `AppKit`):** Захват выделенной области с прицелом и координатами, захват активного окна или всего экрана.
- **Beautifier Studio (Студия оформления):** 
  - Эстетичные градиентные фоны и автобаланс цвета (Smart Background).
  - Настройка отступов (`Padding`, `Inset`), скругления углов (`Corner Radius`) и мягких теней (`Drop Shadow`).
  - Добавление нативной шапки окна macOS («светофор» в темном/светлом стиле).
  - Пресеты соотношения сторон (`Auto`, `1:1`, `4:3`, `16:9`, `9:16`).
- **Векторный редактор со слоями:**
  - Стрелки, прямоугольники, текст, нумерация шагов (`1, 2, 3...`), размытие/блюр.
  - Возможность перемещать и удалять каждый слой отдельно + поддержка `Undo / Redo`.
- **Smart Redact & OCR (`Vision`):**
  - Распознавание текста на русском и английском языках в 1 клик.
  - Автоматический поиск и размытие конфиденциальных данных (Email, телефоны, номера карт, ключи) на скриншоте.
- **Pin to Screen & Quick Overlay:**
  - Всплывающее превью в углу экрана сразу после снимка с поддержкой Drag & Drop.
  - Закрепление скриншота поверх всех окон (`Floating Window`).
- **Темы и Локализация:**
  - Нативная поддержка **Светлой (Light)** и **Темной (Dark)** темы macOS.
  - Мгновенное переключение между **Русским (RU)** и **Английским (EN)** языками прямо в интерфейсе.

## 🚀 Сборка и запуск

### Вариант 1: Через Xcode (Открытие пакета)
1. Откройте папку проекта в терминале или дважды кликните по `Package.swift`, чтобы открыть проект в **Xcode 15+**.
2. Выберите схему `Screenshoti` и целевое устройство `My Mac`.
3. Нажмите `Cmd + R` для сборки и запуска.

### Вариант 2: Генерация `.xcodeproj` через XcodeGen (опционально)
Если у вас установлен `xcodegen` (`brew install xcodegen`):
```bash
xcodegen generate
open Screenshoti.xcodeproj
```
