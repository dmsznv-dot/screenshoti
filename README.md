# Screenshoti

Нативный редактор скриншотов для **macOS 14+**, написанный на Swift / SwiftUI. Снимки и распознавание текста обрабатываются на Mac, без серверной загрузки.

## Возможности версии 1.3

- Нативный интерактивный захват области и окна: пробел переключает режим, окно подсвечивается при наведении, Esc отменяет выбор. Захват всего экрана под указателем через ScreenCaptureKit. Масштаб учитывает реальную плотность пикселей экрана.
- Градиентный фон, автоподбор цветов, отступы, тень и опциональная шапка окна macOS.
- Пропорции Auto, 1:1, 4:3, 16:9 и 9:16 применяются к превью и PNG. Пропорции добавляют фон, не растягивая изображение.
- Стрелки, рамки, текст, нумерация и **непрозрачное скрытие данных**. Выбор, перемещение, изменение текста/шрифта/размера/цвета/толщины и удаление отдельных аннотаций.
- Компактная выпадающая палитра с готовыми цветами и HEX-кодом. Выбор установленного шрифта и размера 8–144 pt для нового и выбранного текста.
- Стартовая проверка доступа к записи экрана: системный запрос, переход в настройки macOS, повторная проверка при возврате и кнопка перезапуска. Захват начинается только после подтверждения доступа.
- Глобальные настраиваемые сочетания для области, окна и экрана, с проверкой повторов и конфликтов регистрации.
- Постоянный стек превью: по умолчанию снизу слева, следующие снимки располагаются выше. В настройках можно выбрать любой угол. При заполнении экрана добавляются колонки и страницы; снимки остаются до закрытия, редактирования или закрепления.
- Undo / Redo; история отмены не переносится на другой снимок.
- OCR на русском и английском через Apple Vision. Автоскрытие распознаёт типичные email, телефоны, номера карт, IPv4 и некоторые форматы токенов. Это эвристика: результат нужно проверить перед отправкой.
- Копирование и сохранение PNG с исходной плотностью пикселей, закрепление снимка поверх окон, превью с Drag & Drop настоящего PNG-файла в Finder и другие приложения, с сохранением исходного разрешения. На время нового захвата собственные окна и превью скрываются.
- Русский / английский интерфейс, системная / светлая / тёмная тема, настройки автокопирования и быстрого превью.

В боковой панели хранятся последние 30 **исходных** снимков текущего запуска. При переключении на другой снимок аннотации сбрасываются. Повторный выбор уже открытого снимка сохраняет текущие правки.

## Использование

1. Перенесите Screenshoti в «Программы» и откройте установленную копию. При первом запуске приложение запрашивает доступ к записи экрана. Включите Screenshoti в «Конфиденциальность и безопасность» → «Запись экрана» (название может включать системное аудио), затем вернитесь в приложение. Если macOS требует перезапуск, воспользуйтесь кнопкой на экране доступа.
2. Выберите режим захвата кнопкой или горячей клавишей.
3. Выберите инструмент под холстом. Инструмент «Курсор» выбирает и перемещает аннотации.
4. Для текста выберите «Текст», кликните на изображении и измените надпись, шрифт и размер в инспекторе справа.
5. Скопируйте результат или сохраните PNG.

Глобальные сочетания по умолчанию: `⌃⌥⌘2` — область, `⌃⌥⌘3` — окно, `⌃⌥⌘4` — весь экран. Их можно изменить или отключить в настройках: нажмите на сочетание и введите новое; Esc отменяет, Delete удаляет назначение. Приложение должно оставаться запущенным; закрытие редактора не отключает сочетания. Если сочетание занято, настройка показывает ошибку регистрации. Отдельное разрешение «Универсальный доступ» для этих сочетаний не требуется.

В редакторе: `⌘C` — копировать изображение, `⌘S` — сохранить, `⌘Z` / `⌘⇧Z` — Undo / Redo. При редактировании полей копирование и отмена остаются у текстового поля. Запись видео, скролл-захват и облачное хранение в этой версии не реализованы.

Если доступ не включается после обновления, завершите старую копию приложения, установите новую в «Программы», удалите старую запись Screenshoti кнопкой «−» в разделе записи экрана и добавьте установленную копию кнопкой «+». Экран с инструкциями доступен в настройках приложения и в меню камеры → «Доступ к захвату экрана…». Текущая локальная подпись привязана к конкретной сборке: macOS может потребовать повторную выдачу доступа после обновления. Для устойчивого доверия между выпусками нужна подпись Developer ID.

Чтобы экспортировать снимок из стека, потяните за само изображение в папку Finder или приложение, принимающее изображения. Перетаскивание копирует исходный снимок, карточка остаётся в стеке. Кнопка редактирования открывает его в редакторе, откуда можно сохранить оформленную версию. Временные PNG для перетаскивания удаляются после 24 часов при следующем экспорте.

## Сборка

Для сборки используйте Xcode 16+ (Swift 6). Само приложение работает на macOS 14+.

```bash
swift build
bash scripts/test.sh
bash build_dmg.sh
```

Скрипт создаёт подписанное локальной подписью приложение в `build_dmg_staging/Screenshoti.app` и `Screenshoti-1.3.0-Installer.dmg`. Для создания только `.app`:

```bash
bash build_dmg.sh --app-only
```

Для универсального установщика Apple Silicon + Intel с установленным Xcode:

```bash
bash build_dmg.sh --arch arm64 --arch x86_64
```

Сборка не использует сертификат Developer ID и не проходит нотариализацию Apple. GitHub Actions запускает тесты на macOS и прикладывает установщик к успешному запуску workflow.

## Проверки

Регрессионные тесты проверяют состояние редактора, изоляцию Undo, Redo, нумерацию, выбор/перемещение/удаление и редактирование слоёв, пропорции, разрешение 1×/2× и пиксели в экспортированной маске скрытия. Также проверяются стартовая выдача и повторная проверка доступа без системных запросов в тестах, сохранность документа при отказе, реальные PNG для перетаскивания с исходным разрешением и типы file URL / PNG. Проверяются сохранение сочетаний, нативные параметры захвата, расположение и переполнение стека превью, типографика и экспорт текста. Интерактивный захват, системные разрешения и расположение нескольких мониторов проверяются вручную на Mac.
